# Dixie Avatar Project OKF
## Architecture
- **Hardware**: ESP32-C3 Super Mini with 128x64 SSD1306 I2C OLED display and buzzer.
- **Network**: Exposes `dixie-avatar.local` via mDNS. 
  - **CRITICAL**: The local network has a 5-second timeout bug when resolving mDNS over IPv6. All clients *MUST* use `curl -4` to force IPv4 and prevent freezing.
- **API**: Listens for HTTP POST on `/anim`. Expects `name` (idle, reading, thinking, typing, attention, ring, error, sleep) and optional `model` string.
- **Display Limit**: C++ truncates model strings to 6 characters. Use external Python abbreviations (like `~/.hermes/agent-hooks/abbr.py`) to pack dense data into 6 chars.
- **Firmware Timeout**: `main.cpp` implements a 5-minute inactivity timeout. If no POST is received for 300,000ms, it reverts to `STNDBY` and sleep mode.
