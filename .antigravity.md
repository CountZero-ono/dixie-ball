# Dixie Ball — Project OKF & Agent Instructions

## Overview
Dixie Ball is an autonomous physical AI Executive Head Terminal sitting on the SER7 workstation desk, embodying the McCoy Pauley ROM construct from William Gibson's *Neuromancer*.

## Architecture Standard (v0.3.0)
- **Primary Brain:** Google Gemini 3.8 Live & 3.8 Live Extended Thinking via bidirectional WebSocket stream.
  - Native speech-to-speech (<400ms turnaround).
  - Automatic intra-sentence code-switching (Russian / English).
  - Asynchronous function calling (audio continues without dead air during tool runs).
- **Secondary Local Brain:** Local Qwen 3.6 35B A3B UD IQ3_S MTP on port 1235 (100% sovereign air-gap).
- **Fast Cloud Fallback:** OpenRouter (`qwen/qwen-3.8-flash` & `deepseek/deepseek-chat`) via audited Stripe prepaid billing.
- **Scope Invariant:** Home Assistant is strictly eliminated from this pipeline. Zero HA Assist dependencies.

## Workstation Hands (`services/desktop_tools.py`)
- **Desktop Navigation:** `switch_workspace` (`hyprctl`), `open_url` (`xdg-open`), `open_obsidian_note` (`obsidian://`), `spawn_terminal` (`kitty`).
- **Homelab Execution:** Whitelisted scripts (`run_homelab_script` for `negatiff_invert`, `zg_index`, `flatline_deck`), hardware telemetry probe (`check_workstation_telemetry`).
- **Memory & Fleet:** Flatline L1 PostgreSQL 16 (`192.168.1.53:5432`) + L3 Qdrant (`192.168.1.44:6333`) hybrid search (`query_flatline_memory`), task stashing to `/VoiceNotes/Inbox/AgentBacklog/` (`stash_agent_backlog`), and agent fleet dispatch (`dispatch_agent_task`).

## Hardware Specifications
1. **Spotpear Ball V2 (Executive Head Terminal):**
   - ESP32-S3, 8MB PSRAM, Wi-Fi 4, BLE 5.
   - MAC: `b8:1f:3f:ac:0e:64`.
   - 1.28" GC9A01 circular IPS LCD (240x240) styled as an amber/green phosphor CRT oscilloscope.
   - Onboard I2S microphone + I2S DAC/Amp (multiplier `2.0`).
2. **ESP32-C3 Desktop Avatar (`desktop-avatar/`):**
   - Standalone C++ PlatformIO micro-firmware with 0.96" SSD1306 OLED (yellow HUD / blue Wall-E ovals).
   - Hostname: `dixie-avatar.local`.
   - REST control: `POST http://dixie-avatar.local/anim?name=<state>`. (Force IPv4 `curl -4`).
